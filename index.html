メインプロジェクト

Nezumi AI

オフライン優先・プライバシー重視の Android ローカルAIチャットアプリ

現在のバージョン: v2.4.0

GitHub リポジトリ リリースノート

主な特徴

オフライン優先

オンデバイス推論ではサーバーへデータを送りません。プライバシーを大切にしています。

マルチモデル対応

GGUF / llama.cpp 系モデルをはじめ、Gemma や各種ローカルモデルに対応。クラウドAPIも追加可能です。

高速ネイティブUI

Android ネイティブ（Kotlin + Jetpack Compose）で動作。GPU / NPU / CPU を活用した推論をサポートします。

画像AI・安全機能

画像生成・処理にも対応。AI Safety Model による安全性チェックを搭載しています。

Mini App Platform

拡張可能な Mini App 実行基盤と SDK を用意。プリセットのインポート・エクスポートにも対応。

最新アップデート (v2.4.0)

llama.cpp 直結化、GPUバックエンド対応、推論プロセス分離、Qwen3-TTS 音声合成などを追加しました。
